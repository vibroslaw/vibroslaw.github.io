# Music visual assets

These files are used by the Music / Sound Map final visual experience layer.

## Playlist windows

Add these files:

```text
public/assets/music/playlists/memory-window.webp
public/assets/music/playlists/conscience-window.webp
public/assets/music/playlists/resistance-window.webp
public/assets/music/playlists/identity-window.webp
public/assets/music/playlists/resilience-window.webp
public/assets/music/playlists/personal-cinematic-window.webp
```

Recommended export:

```text
Format: WEBP
Aspect ratio: 16:10 or 4:3
Suggested size: 1600 x 1000 px
Safe area: keep important details near the centre
Style: dark cinematic, archival, premium, no text baked into image
```

If a file is missing, the cards still render with a gradient fallback.

## Album poster cards

Add these files:

```text
public/assets/music/albums/sztab-raport-z-pamieci.webp
public/assets/music/albums/rap-ort-prawda-sumienia.webp
public/assets/music/albums/unbroken.webp
public/assets/music/albums/vhs-viral-halloween-system.webp
```

Recommended export:

```text
Format: WEBP
Aspect ratio: 16:10 or cinematic poster crop
Suggested size: 1600 x 1000 px
Safe area: centre-left and centre-middle
Style: cinematic album-world poster, no visible UI text required
```
