# Open Graph image assets

This folder contains social preview assets for Veritas Humanum pages.

Current committed assets:

- `veritas-humanum-og.svg` — lightweight generic fallback preview.
- `authorial-profile-og.svg` — dedicated preview for the authorial profile.

Recommended final production assets to add later as JPG files, because many social platforms handle JPG previews more reliably than SVG:

- `veritas-humanum-og.jpg`
- `rap-ort-og.jpg`
- `prawda-sumienia-og.jpg`
- `sztab-og.jpg`
- `music-og.jpg`
- `for-institutions-og.jpg`
- `press-recognition-og.jpg`
- `contact-og.jpg`
- `authorial-profile-og.jpg`
- `witness-report-og.jpg`

Suggested size: 1200 x 630 px.
Suggested format: JPG, under 500 KB when possible.

Important: OG image tags should be added directly in the HTML `<head>` of each canonical page. Runtime JavaScript injection is not reliable for social crawlers.
