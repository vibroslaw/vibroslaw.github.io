## Merge discipline

Use this documentation before opening implementation PRs for:

- public Prawda Sumienia pages,
- exclusive participant pages,
- event-aware QR flows,
- Witness Report / Raport Świadka,
- Record of Participation / Zapis Uczestnictwa,
- anonymous archive features,
- event-specific commemorative pages.

Every implementation PR after this should include:

- Source Pack,
- Institutional Review Mode,
- Scoring Matrix,
- Red Team Pass,
- touched and untouched routes,
- privacy/data impact.

The goal is to keep future implementation work serious, institution-safe, mobile-first, bilingual, source-aware and maintainable.
